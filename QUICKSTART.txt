📦 INSTALLATION
─────────────────────────────────────────────────────────────────────────────

1. Clone the repository
   $ git clone https://github.com/kpraveenkumar182007-commits/ptk-digital-platform.git
   $ cd ptk-digital-platform

2. Install dependencies
   $ npm install

3. Start the application
   $ npm start

4. Open your browser
   http://localhost:3000

📊 DATABASE
─────────────────────────────────────────────────────────────────────────────

Database: SQLite (file-based)
Location: /data/ptk.db
Auto-initialized: Yes (on first run)

Main tables:
• settings - Party branding and website content
• members - Approved members
• membership_applications - Pending/approved/rejected applications
• cards - Membership card records
• announcements - Public announcements
• events - Events
• volunteers - Volunteer registrations
• grievances - Public grievances
• audit_logs - Admin action history


🔧 CONFIGURATION
─────────────────────────────────────────────────────────────────────────────

Environment variables:
  PORT=3000                    # Server port (default)
  SESSION_SECRET="your-key"  # Session encryption
  NODE_ENV=production          # production or development

To set environment variables:
  export PORT=3000
  export SESSION_SECRET="random-secure-string"
  npm start


💾 BACKUP & RESTORE
─────────────────────────────────────────────────────────────────────────────

Backup (automated from admin panel):
  Admin → Backup → Download backup
  Creates JSON file with all data

Restore:
  Admin → Backup → Paste JSON content → Restore
  Replaces all existing data from backup

✓ Keep backups in secure location
✓ Test restore on copy of data first
✓ Admin users NOT included in backups (security)

🐛 TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────────

See RUNTIME-ISSUES.md for detailed solutions.

Quick fixes:

Port already in use:
  $ lsof -i :3000 | grep node | awk '{print $2}' | xargs kill -9

Dependencies missing:
  $ npm install

Database locked:
  $ rm data/ptk.db
  $ npm start  # Reinitialize

Admin login fails:
  • Username: admin
  • Password: admin123
  • Check /data/ptk.db exists
